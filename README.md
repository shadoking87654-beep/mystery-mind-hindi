# Mystery Mind Hindi — Android + Web Starter

## Included
- `index.html`: existing endless/reward prototype carried forward
- `manifest.webmanifest`: installable web app metadata
- `sw.js`: basic offline cache
- `icons/`: app icons

## Important status
This is a PWA starter, not a verified production release. The current game is still a prototype: gameplay modes, progression balancing, data validation, accessibility, and device/browser testing need QA. Progress currently uses browser localStorage and is device/browser-specific. Google login, cloud sync, and ads are not connected.

## Phone-only next steps
1. Upload this ZIP's files to a GitHub repository (keep paths exactly as shown).
2. Enable GitHub Pages for the repository (Settings → Pages → deploy from branch; choose main and root). Wait for the HTTPS site URL.
3. Open the HTTPS site in Chrome on Android and test each mode, reward popup, reload persistence, and offline behavior.
4. To create an Android package from the hosted PWA, open PWABuilder in Chrome and enter the HTTPS URL. Review its checks and Android package options. Build/signing may require a signing key and additional store setup.
5. Before Play Store release: fix all reported issues, add privacy policy and support contact, test on real devices, and follow current Google Play requirements.
6. Add ads only after the game is stable. Choose an appropriate ad SDK/network, follow consent/privacy requirements, and never show ads deceptively or reward users for invalid ad interactions.

## Do not assume
- No APK has been generated by this ZIP.
- No ad network is connected.
- No cloud backup or Google sign-in is connected.
- A GitHub Pages URL and PWABuilder package are not created automatically.
